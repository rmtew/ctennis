# Native visual identity

The game uses the Baseline Rally title and logical Blue/Red player colors.
Classic human/robot sprites preserve A/B ownership through end exchanges.
The title menu uses HUMAN VS AI and HUMAN VS HUMAN. Status text includes
FAULT and DOUBLE FAULT. The retained court font supplies score and status text;
Font-Mac supplies menu and help text.

The native court and title no longer show the Sega logo. Converted assets still
retain their Sega-derived provenance. See [asset provenance](../../assets/native/README.md).

Current appearance contracts and independent masks are in
[the sprite documentation](../sprites/README.md). Native raster tests compare
actual displayed pixels against those contracts. The CT12 before/after pictures
and intermediate validation reports describe an older layout. They remain in
Git history and are not current test fixtures.
