All28 generated512-byte banks match the independently frozen selected-preview contract; the compiled one-pixel advantage-position fault is rejected. Construction takes **21.157942 ms** of emulated elapsed time, before the simulation timer starts. This is a bounded ordinary executable startup observation, including active OS display DMA. Exact executable, contract, tool, measurement inputs and receipt hashes plus bank results are in square-startup.json. Recheck after constructor/contract/product changes with `RUST_LOG=info python scripts/run_native_square_startup.py --self-test`.
