# Z80-to-68000 translator pilot

The local [translator](../scripts/z80268k.py) is adapted from Jean-Francois Fabre (JOTD), [`amiga68ktools` `z80268k.py`](https://github.com/jotd666/amiga68ktools/blob/abc03aabb57ff19c41a9d32317669768c1caf4a4/tools/z80268k.py), pinned to commit `abc03aabb57ff19c41a9d32317669768c1caf4a4`. The import is commit `8ce0278`; subsequent changes are project-specific. The upstream repository has no declared licence in its GitHub metadata, so publication terms need resolution before pushing this copied file to a public repository.

Run `python -W ignore scripts/z80268k.py --champion-source -n -i mot -o mot -c build/translation/champion-raw.68k -I build/translation/z80-support.i --report-output build/translation/report.json build/analysis/champion-tennis-classified.asm` after regenerating the byte-exact annotated source with `python scripts/roundtrip_rom.py`. The adapter keeps the source listing untouched, converts z80asm hex/data syntax in memory, and writes generated outputs under ignored `build/`. It refuses `--no-review` because that would erase unresolved cases. The report hashes the input and output and lists review markers.

The first full-listing pilot parses 2,823 Z80 code lines and 178 data directives. It emits 42 explicit review/error markers, including `im`, SG/SC `in`/`out`, two `jp (hl)` sites, stack-pointer setup, alternate-register/carry-sensitive constructs and flag-liveness warnings. These markers are blockers, not an estimated percentage of correct gameplay. Hardware I/O and interrupt entry must become Amiga adapters. The source uses both direct calls and RAM-based interrupt dispatch; each indirect target needs an explicit translation.

The Motorola output is not assemblable yet. `vasmm68k_mot` first fails inside the upstream Motorola support include at `SET_XC_FLAGS:MACRO`; that include itself says its macros are not up to date. The MIT output has a larger support macro set, but the currently installed vasm binary uses Motorola syntax. The generated code also needs review for 68000-only legality, 8-bit Z80 flags, source stack semantics, Z80 little-endian word accesses and any register aliasing. Do not treat line parsing as semantic translation. The next gate is to repair or replace the Motorola support macros, make all unresolved cases fail at their source locations, assemble a bounded gameplay slice, and compare its RAM with the existing 40-update and 200-update source captures. Only then measure memory and cycles on the unexpanded PAL A500.
